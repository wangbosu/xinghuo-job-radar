# 星火秋招雷达（Xinghuo Job Radar）

面向 2027 届秋招的个人招聘信息台：每天自动扫描官方招聘网站、央国企/国资平台、国家大学生就业服务平台、高校就业网、企业校招门户和可信 ATS，去重后按城市与岗位方向排序。

## 口径

- 正式推荐池只收明确标注“2027 届”且能确认正式校园招聘/全职性质的岗位。
- 社招、日常/暑期实习、兼职、校园大使、强销售、纯客服和重技术岗位会过滤或降到线索池。
- 牛客、公众号等社区来源只作为“待核实线索”，二次确认后才进入正式池。
- 深圳 > 广州 > 成都 > 东莞/佛山/惠州；运营/项目、供应链/计划/交付、市场/品牌/电商、综合职能优先。

## 自动运行

- GitHub Actions 每天北京时间 07:15 快扫稳定信源。
- 每周二、周五 07:35 补扫慢源。
- 运行后自动生成 `data/jobs.html` 并部署到 GitHub Pages。
- 投递看板只保存于浏览器 localStorage，不写入公开仓库。

## 本地运行

```bash
python3 scripts/sync_plan.py rescore
python3 scripts/export_html.py
python3 scripts/smoke_test.py
```

项目不需要 Docker 或常驻电脑；仓库中不放个人姓名、学校、简历和联系方式。
